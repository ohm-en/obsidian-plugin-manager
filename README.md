# Description

A plugin for [ObsidianMD](https://obsidian.md/) which provides better management for other plugins.

## (Manual) Installation

Until the plugin has been published to the community tab, please use the below method to install:

1.  Download the latest `main.js` & `manifest.json` from the latest [release](https://github.com/ohm-en/obsidian-plugin-manager/releases).
2.  Create a folder&#x2013;with any name&#x2013;in `.obsidian/plugins` at your vaults location.
3.  Move the downloaded files into the created folder.
4.  After reloading the Obsidian plugin list, you will see the plugin. Enable it.
